# 고영이 재원화와 실제 원화 파츠 분리 — 2026-11-05

## 요청 및 상태
- 사용자 요청: 거절된 리깅 시안 대신 천천히 다시 그려 제작한다. 고영이 한 종의 자연스러운 오른쪽 3/4 원화부터 다시 맞추는 단계.
- 새 시안은 검토용이며 기존 Approved 및 강아지/햄스터를 교체하지 않았다. 이전 Characters_20261105는 사용자 미채택 이력이다.

## 실제 수행
- 기존 FLUX + BiRefNet ComfyUI 워크플로우로 새 전신 원화 4장(A~D) 생성. 자연스러운 3/4 구도 B를 선택하고 몸 길이를 줄인 입력으로 2회 img2img 다듬기(E/F). E 채택은 에이전트의 검토 선택이며 사용자 승인 아님.
- 선택 E: seed115310, denoise0.35, steps28, CFG1, FluxGuidance3.5, Euler/simple, 768x768. B 초기 생성 seed115302/guidance3.0.
- 꼬리·볼터치·수염을 제거하고 눈썹을 마무리. 손발 끝 일부 작은 선은 남아 있으며 최종 승인 시 추가 단순화 대상.
- 새로 그려진 원화의 실제 팔·다리 경계로 5개 PNG를 분리했다. 기존 얼굴을 옮기거나 타원으로 팔다리를 새로 합성하지 않았다.
- ComfyUI에서 숨겨진 몸통을 부분 복원하고 수정 범위를 실제 파츠에 가려지는 영역으로 한정해 중립 조립 시 원화가 유지되도록 했다.
- 마스크 입력은 좌표/색 분석으로 준비. 원화 생성·수정·관절부 복원·최종 PNG 출력은 ComfyUI만 사용. Python은 입력 마스크 준비, 파일/메시 검사, 실제 PNG의 조립 및 LBS 가중치 검토 렌더에 사용.

## 파일
- ArtPipeline/Rigging/Goyeongi_Redraw_20261105 및 ZIP.
- sprites/ 5개 모두 768x768 RGBA. rig.json은 root(375,575), body(390,430), 어깨/골반 본·피벗을 정의한다. 왼쪽은 리그 전체 반전, 상하는 마지막 좌우 방향을 유지.
- mesh_weights.json은 어깨·골반 가까이는 body, 끝으로 갈수록 해당 limb 본에 smoothstep 가중치를 주는 제안. 실제 Unity SpriteSkin으로 임포트하지 않았다.
- 정확한 최종 API/UI와 입력 파일 매핑, source/B/E 원화 이력, 재실행 도구 포함.
- 사람용: ../Human/Goyeongi_Redraw_Review.html.

## 검증
- 5개 PNG 크기·투명도·비어 있지 않은 관절·몸통 겹침 검사 통과. 일부 PNG 최대 알파254는 ComfyUI float->PNG 반올림이며 전체 투명 모서리는0.
- 중립 조립본과 ComfyUI 조립 원화 평균 RGB 차이 0.513/255 미만.
- 가중치 범위 0~1, 합1, 비퇴화 삼각형 검사 통과. body 고정 관절 LBS 검토 렌더24프레임과 중립/±12도 극값 시각 확인.
- 단순 통회전 검토는 연결부가 드러나 최종 검토 렌더로 사용하지 않았다.
- Unity 에디터 임포트/메시/가중치/클립 실행·게임 통합은 미실행. 큰 동작은 아직 미검증. Client 변경 없음.
