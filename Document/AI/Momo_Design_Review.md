## 기존 후보 평가
크림 바탕 + 코랄·민트·라벤더 색 구분은 유지할 만하다. 눈 광택, 주름·술 장식, 발가락선이 많다. 모모의 앉은 자세와 나머지 후보의 비율이 달라 기본 자세·외곽선·발 위치를 통일해야 한다.

## 제작 및 검증
- 로컬 ComfyUI 0.33.0, RTX 3080 10GB 서버 확인. 기존 모델 파일 이름과 크기를 models.lock.json과 대조. 이번에는 모델 해시 전체를 다시 계산하지 않음.
- 기존 01_character API/UI 그래프를 복제하고 프롬프트·seed·출력 경로만 변경. 원본 워크플로우와 프리셋 미변경.
- 1024x1024, batch 1, steps 10, CFG 2.5, dpmpp_sde/karras, denoise 1.0.
- 20장 생성 성공. 첫 시도는 입체감·털 표현이 과해 제외. 스타일 문장 선두 배치와 단순화로 평면 후보 탐색. 일부 결과는 자세·외곽선·색 지정 미준수로 제외.
- 제시 후보 4종 모두 1024 RGBA, 알파 0~255 확인. 원본과 BiRefNet 출력 보존. 512 캔버스에서 알파 경계 기준 동일 최대 높이 420px, 하단 y466으로 비교용 정렬. 비율은 유지하며 재그리기·색 보정 없음.
- 64/128px 축소 및 흰/어두운 배경 시각 검수. 미세 수염·경계선·잔여 그림자 정리는 최종 제작 단계. 픽셀 단위 최종 마스크 승인은 아님.
- 모든 제시 후보에 API JSON, UI workflow JSON, history, prompt ID 보존. 전체 탐색 프롬프트·seed는 review_manifest.json에 기록.
- Unity 적용·게임 화면·리깅·애니메이션·새 모델 설치 미실행. Client 및 기존 더미 미변경.
