# 블록 그래비티 난이도 조정 — 2026-11-06

## 배경과 구현

사용자 피드백: 재미는 있지만 너무 쉬워 게임 오버가 거의 없고 지루함.
기존에는 1~4칸 조각 10종을 동일 확률로 계속 추첨했다. 매 배치의 셀별 중력 압축 및 가로·세로 동시 삭제와 결합되어 단순 첫 빈자리 배치로도 매우 오래 생존했다.

중력·삭제·콤보·게임 오버 판정은 유지하고 실제 Presenter의 조각 생성기를 ProgressivePieceSource로 교체했다. DefaultPieceSet/PieceBag은 기존 순수 규칙 및 테스트용으로 보존한다. 생성기는 보드 상태를 읽거나 불가능한 조각을 골라내지 않는다. 정해진 단계 풀에서 seed 기반 독립 추첨한다. 시간제한은 추가하지 않았다.

| 완료 배치 수 | 표시 단계 | 다음 트레이의 조각 |
| --- | --- | --- |
| 0~5 | 1 | 기존 10종, 1~4칸 |
| 6~17 | 2 | 기존 3~4칸 조각 + 가로/세로 4칸 직선 및 2×3/3×2 사각형 |
| 18~35 | 3 | 기존 4칸 조각 + 4칸 직선, 6칸 사각형, 3×3, 5칸 모서리 |
| 36 이상 | 4 | 2×3, 3×2, 3×3, 5칸 모서리 |

세 조각 소진 시에만 다음 트레이를 뽑으므로 단계 전환 역시 트레이 경계에서 발생한다. 잘못된 배치·연출 중 입력·일시정지는 진행을 앞당기지 않는다. 재시작 시 첫 단계로 돌아간다.

## 표시와 자산

- 보드 64개 SpriteRenderer는 유지. 트레이 27개, 드래그·미리보기 각 9개로 프리팹 풀 확장.
- BlockGravitySetup.ApplyDifficultyPools는 기존 Playfield 프리팹을 Logs/BlockGravityBackup 아래 백업한 후 참조 배열과 부족한 렌더러만 확장한다. 런타임 오브젝트 추가 없음. 새 리소스 경로 없음.
- HUD 상태 줄에 단계 표시, 큰 조각 대비 안내, 튜토리얼 3단계 설명 갱신. 모든 문구 ko/en StringTable.
- 기존 block_gravity 점수 키·코인·튜토리얼 이력을 보존했다. 과거 쉬운 규칙의 최고점은 그대로 남으므로 새 난이도 기록과 직접 비교할 수 있는 별도 기록 체계는 아니다.

## 검증

Unity 6000.3.16f1 컴파일 오류 없음. 블록 그래비티 Edit Mode 89/89, Play Mode 24/24 통과. 9칸 조각 표시·드래그·중력 이동·재시작, 기존 콤보·메뉴·결과 저장 검증 포함. 1080×1920 화면 확인 완료. 별도 .NET 순수 규칙 74/74는 위 테스트와 겹치는 보조 실행이다.

실제 C# 세션과 최종 생성기로 100 seed × 2 배치 정책 × 신구 규칙 = 400판을 시뮬레이션했다. 500회 배치에서 중단했다.

| 기존 / 첫 유효 위치 | 500 이상 | 500 이상 | 100/100 |
