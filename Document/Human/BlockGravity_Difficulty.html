처음 6개기존 작은 조각으로 시작
6회 이후4칸 직선과 2×3 사각형 등장
18회 이후3×3과 5칸 모서리 등장, 작은 조각 감소

화면에 현재 단계가 표시됩니다. 조각은 계속 3개씩 받고, 5번 놓으면 중력이 회전합니다. 남은 조각을 하나도 놓을 수 없으면 게임 오버입니다. 재시작하면 첫 단계부터 시작합니다.

Unity 6000.3.16f1 컴파일 오류 없음. 블록 그래비티 Edit Mode 89/89, Play Mode 24/24 통과. 9칸 조각 표시·드래그·중력 이동·재시작, 기존 콤보·메뉴·결과 저장 검증 포함. 1080×1920 화면 확인 완료. 별도 .NET 순수 규칙 74/74는 위 테스트와 겹치는 보조 실행이다.
