바로 켜고 끄는 소리 아이콘

Unity 원본 프리팹 적용 완료. Edit Mode 222/222 · Play Mode 18/18 통과. 실제 Boot → 허브 → 게임 → 일시정지 화면과 한국어·영어 전환을 확인했습니다.

바뀐 동작

일시정지 메뉴의 별도 설정창 버튼을 제거하고 배경음·효과음 아이콘 두 개를 넣었습니다. 메뉴 카드 크기는 760 × 740으로 키워 제목, 아이콘, 계속하기·나가기 버튼 사이에 간격을 확보했습니다.

아이콘을 누르면 해당 항목만 전환됩니다. 켜짐은 짙은 녹색, 꺼짐은 회색 아이콘과 빨간 사선으로 표시합니다. 한국어·영어 상태 문구도 함께 바뀝니다. 기존 저장 설정과 SoundManager에 바로 반영되며, 저장 실패 시 원래 상태와 아이콘을 유지하고 안내를 표시합니다.

음소거를 바꾸는 동안 게임은 계속 일시정지 상태입니다. 메뉴를 닫았다가 다시 열어도 저장된 설정을 읽습니다.

모든 문구는 문자열 테이블

메뉴 내부의 제목·버튼·아이콘 이름·ON/OFF·오류 안내는 모두 Client/Assets/_Project/Resources/Data/StringTable.json에 있는 한국어·영어 행을 사용합니다. 정적 제목은 LocalizedText, 동적 상태와 안내는 L10n 조회로 표시합니다.

키한국어English
bg.menu.title잠깐 쉬어가기Take a break
bg.menu.continue계속하기Continue
bg.exit나가기Exit
settings.music배경 음악Music

동적 ON/OFF 라벨은 ILocalizedDynamicText로 구분하여 Localization 메뉴가 정적인 켜짐 문구로 덮어쓰지 않도록 했습니다.

코드·리소스 연결

AudioSettingIcon.cs는 저장 상태 조회, 클릭 전환, 표시와 데이터 변경 구독을 담당합니다. BlockGravityPausePopup.cs는 계속하기·나가기·바깥 클릭 닫기를 담당합니다.

아이콘은 프로젝트의 ComfyUI 기본 마스크 노드로 생성했습니다. Resources/UI/Icons/Audio/Music.png, Effects.png를 부트 목록에 등록하고 프리팹에서 참조합니다. 런타임에 UI를 조립하거나 이미지를 생성하지 않습니다.

이전 게임 설정 팝업은 부트 목록에서 제외하고 Prefabs/Legacy/BlockGravitySettings.prefab에 원본을 보관했습니다. 기존 스크립트는 보관 프리팹의 호환성을 위해 남아 있으며 게임 메뉴에서 열리지 않습니다.

검증

Edit Mode 222개와 Play Mode 18개가 통과했습니다. 배경음·효과음 독립 전환, SoundManager 적용, 진동 설정 보존, 저장 실패 복원·재시도, 재개방 시 상태 복원, 데이터가 없을 때 비활성화를 검사했습니다.

실제 Unity 화면에서 아이콘·텍스트·간격과 영어 전환을 확인했습니다. 설정 저장 테스트는 메모리 저장소를 사용했습니다. 실제 플레이어의 소리 설정은 변경하지 않았습니다. Android 기기에서의 음원 출력 검증은 별도입니다.
