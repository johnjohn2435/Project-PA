콤보가 이어집니다.

콤보 규칙

새로 받는 조각 3개가 한 세트입니다. 그 안에서 한 번이라도 줄을 지우면 콤보가 유지됩니다. 세 개를 모두 썼는데 한 번도 지우지 못하면 끊깁니다.

세트 A: 삭제 → 실패 → 실패
세트 B: 실패 → 실패 → 삭제
네 번 연속 못 지워도, 각 세트에서 삭제했으므로 콤보 유지!

줄을 지운 배치마다 콤보가 1 증가합니다. 한 번에 여러 줄을 지워도 콤보는 한 번만 증가합니다.

콤보1줄 삭제 점수연출
1100점기본 삭제
2200점진동 + 짧은 카메라 흔들림
3300점진동 + 짧은 카메라 흔들림

배치 점수는 칸당 10점 그대로입니다. 삭제 점수에 콤보 배수를 적용하며 기존 동시 삭제·연쇄 점수도 유지합니다. HUD에 현재 콤보와 삭제 배수를 표시합니다.

게임 화면에는 나가기 버튼 하나

나가기 버튼 → 화면 음영 + 게임 일시정지
나가기 / 계속하기 / 설정

나가기는 현재 판을 끝내고 허브로 돌아갑니다. 계속하기 또는 팝업 바깥 클릭은 메뉴를 닫고 게임을 재개합니다. 카드 안의 빈 공간을 눌러도 닫히지 않습니다.

설정에서 배경음·효과음·진동을 바꿀 수 있습니다. 설정 바깥이나 뒤로가기를 누르면 설정만 닫히고 일시정지 메뉴로 돌아옵니다. 설정 저장에 실패하면 기존 값을 유지하고 다시 시도할 수 있습니다.

팝업의 전체 화면 패널이 뒤쪽 입력을 차단합니다. 메뉴는 일반 UI 위에, 설정은 메뉴 위에 표시합니다.

흔들림과 진동

2콤보부터 삭제 시 한 번씩 발생합니다. 카메라 흔들림은 약 0.2초 동안 약해지며 HUD와 팝업은 고정됩니다. 일시정지·재시작·화면 이동 시 카메라는 제자리로 돌아옵니다.

Android 진동은 게임의 진동 설정과 기기의 터치 햅틱 설정을 따릅니다. PC와 Unity 에디터에서는 진동하지 않습니다.
