코드 구조와 리소스

  • SaveData / PlayerProfile / DataManager: 저장 v3, 이전 ID 변환, 튜토리얼 완료 저장
  • BlockGravityTutorialPopup: 3단계 표시·재시도·나중에 보기
  • BlockGravityPresenter / SoundManager / AudioPaths: 게임 이벤트와 캐시된 사운드 연결

  • CharacterRigPreview: 허브의 캐릭터·카메라 인스턴스 수명
