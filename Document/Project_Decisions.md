# 프로젝트 결정 및 검토 기록

이 문서는 최초 MVP 명세 이후의 사용자 지시를 기록한다. 충돌하는 항목은 최신 사용자 결정이 우선하며, 검토 중인 항목을 확정된 요구사항으로 취급하지 않는다.

## 2026-09-17 — 저장소와 개발 환경

- 저장소 루트: `D:\Project PA`
- Unity 프로젝트 루트: `D:\Project PA\Client`
- 기획·개발 문서: 저장소 루트의 `Document/`
- 현재 설치·생성·검증에 사용한 Unity: `6000.3.16f1`
- 최초 명세의 기준: `6000.3.23f1` 이상 Unity 6.3 LTS.
- 현재 버전 유지는 작업용 임시 상태다. 명세 기준 버전의 설치와 업그레이드 검증은 아직 완료하지 않았다.
- 에디터 버전 문자열만 바꿔 업그레이드한 것으로 취급하지 않는다.

## 2026-09-17 — 패치 방향

- 사용자 의사: 패치는 Unity Addressables를 사용하는 방향.
- 지금은 방향만 기록한다. 패키지 설치, 패치 다운로드 UI, 원격 카탈로그·번들 구성, 배포는 수행하지 않는다.
- 도입 시점, 콘텐츠 범위, 호스팅/CDN, 버전 관리 및 실패 복구 정책은 추후 결정한다.
- 원래 명세의 Addressables 제외는 현재 단계의 구현 보류를 의미하며, 향후 도입 자체를 금지하지 않는다.

## 2026-09-17 — 서버 검토안 (미정)

- 서버를 붙일 경우 DB 후보는 Supabase.
- 애플리케이션 서버는 웹서버를 사용하는 방안을 생각 중.
- 게임 서버 도입 여부, 기술 스택, 호스팅, Google 계정 연동의 구체적인 인증 구현 방식과 데이터 구조는 아직 결정되지 않았다.
- 이 메모는 구현 지시가 아니다. Supabase SDK, 서버 프로젝트, 계정, 인증키, 외부 인프라는 추가하지 않는다.
- 게스트 플레이는 로컬에서 완결되는 구조를 유지한다. 아래의 선택적 Google 계정 연동 요구사항은 별도로 반영한다.

## 2026-09-17 — 씬 흐름 및 선택적 계정 연동

- 씬 흐름은 `BootScene → SelectScene → GameScene`으로 확정한다.
- `BootScene`: 초기화와 로컬 데이터 로드 후 SelectScene 진입. 로그인 필수 관문을 두지 않는다.
- `SelectScene`: 게임·캐릭터 선택 및 계정 연동 진입점. 미연동 상태에서 언제든 Google 계정 연동을 시작할 수 있어야 한다.
- `GameScene`: 선택된 미니게임 실행. 첫 미니게임 이름은 Block Gravity이며 씬 파일 이름은 GameScene이다.
- 로그인 없이 게스트로 게임을 플레이할 수 있어야 한다.
- Google 계정 연동 취소·실패가 게스트 플레이를 막지 않도록 한다.
- 이번 변경은 씬 상수·설정 도구·설계 문서에 반영한다. 인증 SDK·서버 통신은 아직 구현하지 않는다.
- 인증 제공자 구성, Google 연동 세부 방식, 게스트 데이터 이전·병합, 계정 해제, 클라우드 저장 도입 여부와 구현 시점은 미정이다.
- Supabase DB와 웹서버 구상은 여전히 검토안이며, 이 요구사항만으로 특정 백엔드를 확정하지 않는다.
